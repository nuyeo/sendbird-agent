# /test - 테스트 실행 및 분석

## 사용법
```
/test $ARGUMENTS
```

## 지시사항

1. `$ARGUMENTS`에 따라 테스트를 실행합니다:
   - 인자 없음: `pytest -v` (전체 테스트)
   - 파일명: `pytest -v $ARGUMENTS`
   - 키워드: `pytest -v -k "$ARGUMENTS"`

2. 테스트 결과를 분석합니다:
   - 통과/실패/스킵 개수 요약
   - 실패한 테스트가 있으면 상세 원인 분석

3. 실패한 테스트가 있는 경우:
   - 에러 메시지와 스택 트레이스를 분석합니다
   - 관련 소스 코드를 읽어 원인을 파악합니다
   - 수정 방안을 제안합니다
   - 사용자 승인 후 수정을 적용합니다

4. 모든 테스트가 통과하면 결과 요약을 출력합니다.
